# Archivo (solo lectura)

Material del flujo anterior OpenSpec/SDD, conservado como historial. **No se usa para trabajo nuevo.**

- `openspec/specs/`: specs de features ya implementadas. Su contenido vigente está volcado en `docs/areas/`.
- `openspec/changes/`: proposals, designs, tasks y verify-reports de cada change.
- `sdd/`: exploraciones previas.
